# Escuela API

- Ejecutar Node, npm, migraciones, importaciones y pruebas exclusivamente en Docker.
- No instalar dependencias en el host. Usar volúmenes Docker para node_modules y .next.
- Arquitectura: Next.js App Router + TypeScript + PostgreSQL; frontend y REST separados por responsabilidades.
- No automatizar descargas, importaciones ni publicación de datos. Son acciones manuales del mantenedor.
- No agregar votos, aportes, reportes comunitarios, cuentas ni rankings al MVP.
- No inventar datos ni interpretar ausencias como cierres de escuelas.
- Conservar CUE y anexo como texto, fuente, corte y trazabilidad.
- No publicar secretos, archivos originales grandes ni backups en Git.
- Revisar docs/MVP_PLAN.md antes de ampliar alcance.

- Excepción autorizada por el usuario (04/11/2026): interacción «Asistí acá» como marca personal reversible en localStorage. No implica votos, contadores públicos, cuentas ni verificación de asistencia.

- Ampliación autorizada 04/11/2026: contador público anónimo «Asistí acá», reversible, con cookie firmada, límites y unicidad transaccional. Sin estrellas, rankings ni verificación de identidad. Datos adicionales y noticias: investigación web y carga manual con fuentes.
